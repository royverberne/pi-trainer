# π Trainer

Leer de decimalen van π, groepje voor groepje. Een educatieve app van Meester Roy voor groep 5 t/m 8.

- `index.html`: de volledige app (één bestand, geen build nodig)
- `pi-decimalenlijst.pdf`: de afdrukbare lijst met alle 1000 decimalen

Voortgang wordt alleen in de browser van het toestel bewaard (geen accounts, geen server).
